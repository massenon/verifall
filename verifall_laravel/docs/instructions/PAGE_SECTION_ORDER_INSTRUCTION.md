# PAGE_SECTION_ORDER_INSTRUCTION.md — Ordre canonique des sections

**Toute page connectée** : Breadcrumb → Page header (titre+desc+actions, 1 CTA primaire max) → Contexte/alertes → **KPI (accordéon mobile)** → Filtres/recherche → Contenu principal (workspace) → Widgets secondaires → Pagination → Footer.
**Dashboards** (hiérarchie §37) : Contexte (hero salutation+statut) → KPI → Alertes/« À traiter maintenant » → Analytics → Travail opérationnel → Activité → Secondaire. Jamais commencer par des graphiques.
**Pages publiques** : Hero → Preuve/valeur → Fonctionnalités → Comment ça marche → Témoignages/partenaires → FAQ → CTA final → Footer (ordre exact du prototype par page).
**Cours** : Hero cover → tabs (Aperçu, Curriculum, Instructeur, Avis, Quiz, Exercices, FAQ dans cet ordre) → sidebar sticky (CTA, contenu, méta).
**Rapport** : Verdict hero → score/confiance → synthèse → claims → Sources et Preuves consultées → méthodologie → partage.
L'ordre est vérifié en revue : toute inversion = refus.
