# DICTIONNAIRE_DONNEES_COMPLET.md (source : docs/kb/03_DATABASE_ENGINEERING.md — résumé opérationnel)

Conventions : tables snake_case pluriel ; PK `id` bigint interne + `uuid` char(36) unique **exposé** ; timestamps + softDeletes sur entités métier ; FK indexées `cascadeOnDelete` réfléchi ; Enums stockés string + cast PHP Enum ; montants en int (unités / centimes FCFA).
Tables cœur (colonnes clés) : users(uuid, name, email uq, phone enc, password, role, units int, xp, streak_days, tour_done_at, otp_verified_at) · consents(user, type, version, ip, at) · signalements(uuid, user, type, payload json, status, priority, cost_units) · analysis_reports(uuid, signalement uq, verdict, confidence, summary, claims json, hsi_flags json, reviewed_by) · evidences(report, source_url, source_name, published_at, stance, reliability, excerpt) · unit_logs(uuid, user, kind analyse|recharge|bonus|remboursement, delta int, ref) · trusted_sources(name, url, category, reliability, audited_at) · courses/sections/lessons/quizzes/questions/answers/assignments · enrollments(user+course uq, status, progress) · lesson_completions(uq user+lesson, seconds) · quiz_attempts(score, passed, duration_s) · reviews(uq user+course, rating, comment) · certificates(uuid, code uq public, user, course, issued_at, revoked_at) · threads/replies/thread_votes(uq user+thread)/reports · hub_articles/portals/jobs · badges/user_badges · referrals(code uq, referrer, referred, status) · newsletters/campaigns · notifications (Laravel) · audit_logs(actor, action, module, target_type+uuid, ip, ua, before json, after json) · security_logs · backups/cron_runs.
Règle : toute nouvelle colonne = mise à jour de ce dictionnaire dans la même PR.
